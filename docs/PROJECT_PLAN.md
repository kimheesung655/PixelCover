# PixelCover 개발 계획

한국어 서비스를 우선 개발한다. Next.js App Router 화면에서 클라이언트 모듈을 호출하고 정적 결과물을 Cloudflare Pages에 배포할 수 있게 구성한다. 광고는 별도 승인 후 검토한다.

| 담당 | 경로 | 책임 |
| --- | --- | --- |
| 프론트엔드 | src/app, src/components, src/hooks, public | React·Tailwind 기반 화면, 파일 선택, 포인터 입력, 접근성, SEO 및 서비스 메타데이터 |
| 백엔드 | src/lib/image, src/lib/canvas, src/lib/editor | 파일 검사와 디코딩, 픽셀 처리, 영역과 편집 이력 |
| 백엔드 | tests/unit | 엔진 함수와 경계값 검증 |
| 공동 | tests/e2e | Playwright에서 실제 브라우저의 입출력과 UI 연동 검증 |
| 공동 | src/types/editor.ts, docs/API_CONTRACT.md, package.json, 설정 파일 | 계약, 도구 버전 및 빌드 방식 합의 |

아래 표의 각 번호를 하나의 기능·테스트·커밋 단위로 진행한다. 경로는 첫 소스가 생길 때 생성한다.

| 단계 | 커밋 단위 | 검증 기준 |
| --- | --- | --- |
| BE-01 | ① 공통 초기 설정 및 역할·계약 초안 ② Vitest와 TypeScript 실행 환경 연결 | 설정 검사, 이후 샘플 테스트와 타입 검사 |
| BE-02 | ① 파일 시그니처와 형식 오류 ② 바이트 수 제한 ③ 헤더 해상도와 픽셀 예산 | JPEG·PNG·WebP, 손상·불일치, 각 한계값 전후 |
| BE-03 | ① 실제 디코딩 및 손상 오류를 검증에 연결 ② 방향 보정과 원본 치수 ③ 리소스 수명 관리 | 손상 본문, 회전 JPEG, 성공·실패 시 해제 |
| BE-04 | ① 표시 좌표 변환 ② 영역 정규화 | 확대·축소, 여백, 역방향 드래그, 경계 |
| BE-05 | ① 강도별 모자이크 | 영역 안 픽셀 변화와 바깥 픽셀 동일성 |
| BE-06 | ① 강도별 블러 | 가장자리 및 여러 영역에서 외부 픽셀 보존 |
| BE-07 | ① 불투명 덮어쓰기 ② 중첩 렌더링 순서 | 알파 255, 중첩 후 원본 색상 비노출 |
| BE-08 | ① 영역 추가·중복 검사 ② 이동·수정 ③ 삭제 ④ 이력 복원 ⑤ 이력 상한 | 순서, Undo·Redo, 새 편집 후 Redo 폐기 |
| BE-09 | ① PNG 출력 ② JPEG 품질·배경 ③ 파일명 생성 ④ 메타데이터 검사 | 원본 치수, 투명도, 평탄화, 원본 EXIF 미포함 |
| BE-10 | ① 공개 진입점 및 호출 예시 ② 브라우저 통합 테스트 | 미리보기와 출력 비교, 파일 선택부터 다운로드까지 외부 전송 검사 |
| BE-11 | ① 고해상도 메모리 최적화 ② 브라우저 호환 오류 처리 | 반복 편집 및 해제, 데스크톱·모바일 브라우저 검사 |

프론트엔드는 화면 구조, 파일 선택, 편집 화면, 영역 조작, 효과 연결, 이력 버튼, 다운로드, 모바일 접근성, SEO, 통합 테스트 순서로 진행한다.
